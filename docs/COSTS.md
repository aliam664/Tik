# هزینه و محدودیت سرویس‌ها — DOZ ONLINE

به‌روزرسانی: ۲۰۲۶-۱۰-۱۷ — قبل از تصمیم مالی، همیشه اعداد رسمی را در سایت سرویس‌ها چک کنید.

## Supabase (پلن Free)

| منبع | سقف رایگان | وضعیت مصرف این پروژه |
|---|---|---|
| دیتابیس | ۵۰۰ مگابایت | هر اتاق < ۲ کیلوبایت و بعد از انقضا حذف می‌شود → ده‌ها هزار اتاق/ماه قابل تحمل |
| پهنای باند egress | ۵ گیگابایت/ماه | هر حرکت ~۱-۲ کیلوبایت → صدها هزار حرکت/ماه |
| Realtime | هم‌زمان ۲۰۰ کاربر، ۱۰۰ پیام/ثانیه | هر اتاق دقیقاً ۲ subscriber؛ broadcast فقط در تغییر وضعیت — برای چند صد بازی هم‌زمان کافی است |
| Monthly Active Users | ۵۰,۰۰۰ | هر مهمان یک MAU محسوب نمی‌شود (بدون Auth GoTrue)؛ فقط مدیر |
| توقف پروژه | پس از ۷ روز بی‌فعالیتی پروژه Pause می‌شود | بازی نداشتنِ یک هفته → پنل → Restore |

**نقطه شکست:** عبور از ~۲۰۰ بازیکن هم‌زمان Realtime یا ۵GB پهنای باند → پلن Pro ($25/ماه).

## سناریوی رشد

- **۱۰۰ کاربر روزانه (۲۰ بازی هم‌زمان):** رایگان کامل
- **۱۰,۰۰۰ کاربر روزانه (~۱,۰۰۰ بازی هم‌زمان):** Realtime و egress تحت فشار → Pro Supabase ($25) + احتمالاً Business ($599 در صورت نیاز به SLA) — با کانفیگ فعلی، گلوگاه اول Realtime هم‌زمانی است نه دیتابیس
- **بهینه‌سازی ارزان پیش از ارتقا:** طول عمر پیام‌ها، heartbeat کمتر (۱۵s → ۲۵s)، فشرده‌سازی payload

## محدودیت‌های منطقه‌ای (کاربر: ایران)

- Supabase و Cloudflare حساب ایران را محدود می‌کنند؛ پرداخت با کارت ارزی معتبر بین‌المللی لازم است. دور زدن با اطلاعات هویتی جعلی توصیه/انجام نمی‌شود.
- راه جایگزین قانونی و مستند: اجرای خودمیزبانی‌شده — PostgreSQL + PostgREST/Supabase self-host روی سرور خارجی قابل‌دسترس، یا سرویس‌های مشابه با دسترسی منطقه‌ای شما. ساختار پروژه (Migration های استاندارد SQL بدون وابستگی Vendor در کد فرانت) عمداً portable نگه داشته شده است.
