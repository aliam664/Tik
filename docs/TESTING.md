## ۶. چک‌لیست تست انسانی پیشنهادی (۲ دقیقه)

1. دو پنجره مرورگر (عادی + ناشناس) باز کنید
2. پنجره ۱: «ساخت اتاق» → نام → کد را کپی کنید
3. پنجره ۲: «ورود به اتاق» → کد + نام → بازی شروع می‌شود
4. حرکت هر پنجره باید فوراً در دیگری دیده شود
5. یک بازی کامل تا برد/مساوی → هر دو «بازی مجدد» را بزنند → بازی دوم با نوبت متناوب شروع می‌شود
6. پنجره ۲ را Refresh کنید → وضعیت بازی حفظ می‌شود
7. اینترنت پنجره ۲ را قطع کنید → وضعیت «قطع» نمایش داده می‌شود
8. `/admin` → ورود → داشبورد آمار، بستن اتاق، تغییر تنظیمات
